# 🧩 Sudoku Solver using Java

## 📌 Project Overview
A console-based Sudoku Solver developed using Java. It uses the Backtracking algorithm to solve Sudoku puzzles by checking valid number placements.

## 🛠️ Concepts Used
- Core Java
- 2D Arrays
- Recursion
- Backtracking

## ⚙️ Key Features
- Validates rows and columns.
- Checks 3×3 subgrids.
- Places valid numbers in empty cells.
- Uses recursion and backtracking to find a solution.

## ▶️ How to Run
1. Clone or download this repository.
2. Open the project in a Java IDE.
3. Compile and run `Sudoku.java`.
